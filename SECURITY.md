# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security and integrity of `local-jev` seriously. If you discover a security issue or vulnerability, please **do not open a public issue**.

Instead, please send an email with detailed reproduction steps to:
**ronitgupta138@gmail.com**

### What to include
- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact and exploit scenario.
- Any suggested remediations or mitigations.

You will receive an acknowledgment within 48 hours, followed by regular updates until a patch is deployed and released.
